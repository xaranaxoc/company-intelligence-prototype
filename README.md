# SiteScope — анализ компании и сбор данных для лендинга

Локальный сервис: вводите ссылки на источники компании (Instagram, 2ГИС, Яндекс Карты, сайт),
сервис собирает факты, услуги, цены, логотип и фотографии, ИИ-агент строит структурированный бриф
для лендинга, а вы экспортируете архив, который можно скормить любому ИИ-агенту («сделай мне лендинг, вот данные»).

## Запуск

1. Установите [Node.js 22+](https://nodejs.org) (нужен для работы сервиса и Codex CLI).
2. Двойной клик по `start.bat` — при первом запуске поставятся зависимости, затем откроется браузер `http://localhost:3777`.

Остановка — закрыть окно консоли или `Ctrl+C`. Все данные переживают перезапуск.

## Как пользоваться

1. **Настройки → провайдер ИИ.** По умолчанию используется локальный `codex exec` (нужен установленный и авторизованный [Codex CLI](https://github.com/openai/codex)). Либо укажите свой OpenAI-совместимый API (Base URL + ключ + модель).
2. **Новый анализ** — вставьте 1–4 ссылки на источники компании и нажмите «Запустить анализ».
   Анализы можно запускать параллельно: каждый идёт независимо, статусы видны в «Истории»;
   вежливые паузы для одного домена соблюдаются всеми заданиями сообща.
3. Дождитесь завершения (обычно 1–5 минут), откройте отчёт: обзор, данные, медиа, структура сайта.
4. **Экспортировать → «Архив данных»** — ZIP со структурированной информацией о компании
   (`company-data.md` + `company-brief.json`) и папкой `media/` (логотип, фото).
   Отдайте архив ИИ-агенту — он сам придумает дизайн сайта на основе данных.

## Браузерный бустер (2ГИС / Яндекс Карты / Instagram)

2ГИС и Яндекс Карты закрывают данные от серверных запросов (JS-заглушкой и капчей), Instagram — стеной входа.
Что делает сервис:

- **2ГИС** — фотогалерея и витрина товаров с ценами берутся из открытых API 2ГИС напрямую (без браузера),
  а карточка организации (название, адрес, телефоны, рейтинг) — со страницы, открытой в **настоящем Edge/Chrome**
  в видимом режиме: только такой браузер проходит их проверку. Окно появляется на время анализа и закрывается само
  (можно отключить в настройках, тогда карточка будет неполной).
- Обычные сайты собираются и без бустера; для JS-приложений бустер рендерит страницу.
- Установка бустера (один раз, ~150 МБ): кнопка **«Установить бустер»** в Настройках или `npm run browser`.
  Нужен реальный Edge или Chrome на машине (на Windows 10/11 Edge есть всегда).

Без бустера заблокированный источник честно помечается в отчёте — сервис не выдумывает данные.

## Защита от банов

- между запросами к одному домену — задержка (по умолчанию 2.5 с + случайный джиттер), настраивается в Настройках;
- повторные попытки только с нарастающим таймаутом;
- обход подстраниц сайта ограничен (по умолчанию 4 страницы: услуги, цены, контакты…).

## Архитектура

```
start.bat            запуск (npm install при первом старте, открытие браузера)
server.js            HTTP-сервер, API, статика
lib/db.js            SQLite (node:sqlite): компании, источники, медиа, задания, настройки
lib/fetcher.js       вежливый загрузчик: задержки по доменам, ретраи, лимит размера
lib/extract.js       разбор HTML: мета, JSON-LD, контакты, картинки, цены, текст
lib/adapters.js      Instagram / 2ГИС / Яндекс Карты / сайт (+подстраницы)
lib/ai.js            Codex CLI и OpenAI-совместимый провайдер, строгий JSON, эвристический фолбэк
lib/browser.js       опциональный Playwright-бустер для JS-защищённых площадок
lib/media.js         скачивание медиа: фильтры по размеру, дедупликация по хэшу
lib/jobs.js          пайплайн: ссылки → сбор → ИИ → медиа → отчёт (прогресс, отмена)
lib/export.js        экспорт: ZIP / JSON / TXT со структурированными данными
public/              фронтенд (дизайн-прототип, подключён к API)
data/                SQLite-база и скачанные медиа (не коммитится)
```

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | состояние, провайдер, бустер |
| GET/PUT | `/api/settings` | настройки (провайдер, задержки, лимиты) |
| POST | `/api/settings/test` | проверка Codex CLI или своего провайдера |
| GET | `/api/browser/status` · POST `/api/browser/install` | статус и установка Playwright-бустера |
| POST | `/api/analyze` | запустить анализ `{instagram, twogis, yandex, website}` |
| GET | `/api/jobs/:id` · POST `/api/jobs/:id/cancel` | прогресс/лог, отмена |
| GET | `/api/companies` · `/:id` · DELETE `/:id` | история и отчёты |
| GET | `/api/companies/:id/export?format=zip\|json\|txt` | экспорт |

## Ограничения (честно)

- Instagram: часть профилей недоступна без авторизации — источник помечается как заблокированный.
- 2ГИС/Яндекс: без бустера почти всегда блокируют серверные запросы.
- Данные, которых нет в источниках, не выдумываются: ИИ instructed возвращать пустые значения, спорное попадает в `warnings`.
