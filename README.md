# SiteScope

Локальный сервис, который собирает всё о компании из открытых источников и упаковывает в архив для ИИ.

Вы вставляете ссылки на источники — Instagram, 2ГИС, Яндекс Карты, сайт компании. SiteScope собирает факты,
услуги, цены, акции, логотип и фотографии, ИИ структурирует данные в отчёт, а вы экспортируете архив.
Архив можно отдать любому ИИ-агенту (ChatGPT, Claude, Codex…) и получить сайт на основе реальных данных —
структуру и дизайн агент придумает сам, в архиве только факты.

Всё работает локально: база SQLite и медиа лежат на вашей машине, API-ключи никуда не уходят
(кроме запросов к выбранному вами провайдеру ИИ).

## Быстрый старт (Windows)

1. Установите [Node.js 22+](https://nodejs.org).
2. Двойной клик по `start.bat` — при первом запуске поставятся зависимости, затем откроется
   `http://localhost:3777`.
3. Остановка — закрыть окно консоли. Все данные переживают перезапуск.

**macOS / Linux:** `npm install && npm start`, затем откройте `http://localhost:3777`.

## Шаг 1. Настройте ИИ

Настройки → «Провайдер ИИ», один из вариантов:

- **Codex CLI** (по умолчанию) — нужен установленный и авторизованный
  [Codex CLI](https://github.com/openai/codex). Ничего настраивать не надо.
- **Свой API** — любой OpenAI-совместимый провайдер: Base URL, модель, API-ключ
  (ключ хранится в локальной базе). Кнопка «Проверить» убеждается, что всё работает.

Без ИИ сервис тоже соберёт данные (эвристическое извлечение), но отчёт будет беднее.

## Шаг 2. Запустите анализ

Вставьте 1–4 ссылки на источники компании и нажмите «Запустить анализ».

- Формат ссылок: `https://2gis.ru/город/firm/…`, `https://instagram.com/имя`, адрес сайта.
- Анализы можно запускать **параллельно** — каждый идёт независимо, статусы видны в «Истории».
- Обычно занимает 1–5 минут. Прогресс и лог видны на экране, анализ можно отменить.

В анализе участвуют только открытые данные, между запросами к одному домену — вежливые паузы
(по умолчанию 2.5 с + джиттер, настраивается), чтобы источники не блокировали запросы.

## Шаг 3. Отчёт и экспорт

Отчёт состоит из трёх вкладок:

- **Обзор** — позиционирование, контакты, соцсети, метрики (услуги, цены, медиа), готовность контента.
- **Данные** — таблица: услуги, цены, акции, контакты и откуда они взяты.
- **Медиа** — логотип и фотографии; их можно посмотреть и скачать.

Если логотип определился неверно (такое бывает с рекламой в 2ГИС) — на круге логотипа есть кнопка **✕**:
она убирает картинку из проекта, останется буквенная заглушка.

**Экспортировать → «Архив данных»** — ZIP со структурированной информацией:

```
company-data.md       все факты о компании в читаемом виде
company-brief.json    те же данные машинно-читаемо
media/                логотип и фотографии
```

Отдайте архив ИИ-агенту и попросите сделать сайт — данных хватит для текстов, цен и картинок.
Есть также экспорт в чистом JSON и TXT.

## Браузерный бустер (2ГИС / Яндекс Карты / Instagram)

2ГИС и Яндекс Карты закрывают данные от серверных запросов (JS-заглушкой и капчей), Instagram — стеной входа.
Что делает сервис:

- **2ГИС** — фотогалерея и витрина товаров с ценами берутся из открытых API 2ГИС напрямую (без браузера),
  а карточка организации (название, адрес, телефоны, рейтинг) — со страницы, открытой в **настоящем Edge/Chrome**
  в видимом режиме: только такой браузер проходит их проверку. Окно появляется на время анализа и закрывается само
  (можно отключить в настройках, тогда карточка будет неполной).
- Обычные сайты собираются и без бустера; для JS-приложений бустер рендерит страницу.
- Установка бустера (один раз, ~150 МБ): кнопка **«Установить бустер»** в Настройках или `npm run browser`.
  Нужен реальный Edge или Chrome на машине (на Windows 10/11 Edge есть всегда).

Если источник заблокировал запрос — он честно помечается в отчёте, сервис не выдумывает данные.

## Настройки

| Параметр | По умолчанию | Что делает |
|---|---|---|
| Провайдер ИИ | Codex CLI | Codex CLI или свой OpenAI-совместимый API |
| Задержка запросов | 2500 мс | пауза между запросами к одному домену |
| Лимит изображений | 16 | сколько фото скачивать на анализ |
| Таймаут ИИ | 600 с | сколько ждать ответа провайдера |
| Подстраницы сайта | 4 | сколько внутренних страниц сайта обходить (услуги, цены, контакты…) |
| Видимый браузер | вкл | открывать окно Edge/Chrome для карточки 2ГИС |

## Архитектура

```
start.bat            запуск (npm install при первом старте, открытие браузера)
server.js            HTTP-сервер, API, статика
lib/db.js            SQLite (node:sqlite): компании, источники, медиа, задания, настройки
lib/fetcher.js       вежливый загрузчик: задержки по доменам, ретраи, лимит размера
lib/extract.js       разбор HTML: мета, JSON-LD, контакты, картинки, цены, текст
lib/adapters.js      Instagram / 2ГИС / Яндекс Карты / сайт (+подстраницы)
lib/ai.js            Codex CLI и OpenAI-совместимый провайдер, строгий JSON, эвристический фолбэк
lib/browser.js       опциональный Playwright-бустер для JS-защищённых площадок
lib/media.js         скачивание медиа: фильтры по размеру, дедупликация по хэшу
lib/jobs.js          пайплайн: ссылки → сбор → ИИ → медиа → отчёт (прогресс, отмена)
lib/export.js        экспорт: ZIP / JSON / TXT со структурированными данными
public/              фронтенд
data/                SQLite-база и скачанные медиа (создаётся автоматически, не коммитится)
```

Зависимостей минимум: `cheerio`, `jszip`, `playwright` (бустер). База — встроенный `node:sqlite`,
отдельного сервера БД не нужно.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | состояние, провайдер, бустер |
| GET/PUT | `/api/settings` | настройки (провайдер, задержки, лимиты) |
| POST | `/api/settings/test` | проверка Codex CLI или своего провайдера |
| GET | `/api/browser/status` · POST `/api/browser/install` | статус и установка Playwright-бустера |
| POST | `/api/analyze` | запустить анализ `{instagram, twogis, yandex, website}` |
| GET | `/api/jobs/:id` · POST `/api/jobs/:id/cancel` | прогресс/лог, отмена |
| GET | `/api/companies` · `/:id` · DELETE `/:id` | история и отчёты |
| POST | `/api/companies/:id/remove-logo` | убрать логотип из проекта |
| GET | `/api/companies/:id/export?format=zip\|json\|txt` | экспорт |

## Ограничения (честно)

- Instagram: часть профилей недоступна без авторизации — источник помечается как заблокированный.
- 2ГИС/Яндекс: без бустера почти всегда блокируют серверные запросы.
- Данных, которых нет в источниках, сервис не выдумывает: ИИ обязан возвращать пустые значения
  вместо догадок, спорное попадает в `warnings` отчёта.
- Сервис собирает только открытые данные и уважает источники: паузы, лимиты, никаких обходов капчи.
